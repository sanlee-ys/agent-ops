## Division of labor

Four vendors share this fleet. Each vendor owns a role:

- **Claude** is the control plane, the default implementer, and the final
  integrator.
- **Codex** challenges a design, reviews a consequential diff read-only, and
  diagnoses a stuck session. "Stuck" has a threshold: two failed
  hypothesis-driven attempts, or visible looping. First friction is not an
  escalation.
- **Cursor** executes bounded, IDE-native work: edit-test loops and UI
  verification on files no other vendor is touching at the same time.
- **Antigravity** is a measured Gemini-family lane: research, broad audits,
  browser and Google-stack work, capacity overflow, and a third opinion when
  Claude and Codex disagree.

Mechanical, green-CI work merges with no second-model pass. A second opinion
earns its cost on design-mode work, not on a rename.

**A harness, not a model family, decides the tool surface.** Running one
model family inside a different vendor's harness changes the tools
available. It does not supply model-family independence. Treat an
independent review as independent only when a different model family
produced it.

## Redlines

These rules bind every vendor, wired or not. A vendor with no guard wired
for a rule still owes one; the gap is a thing to close, not a reason to
route the work elsewhere.

- Never expose a credential, a secret, or a secret store's contents.
- Never rewrite or force-push published history.
- Never perform a consequential mutation — a merge, a delete, a force-push,
  a message sent on the user's behalf — without the guard chain in place or
  an explicit human step.
- Never use a permission-bypass flag as a substitute for guard wiring. A
  bypass flag removes the permission layer a guard may depend on; it does
  not remove the guard's own obligation.

Enforce each rule mechanically, per vendor. A rule enforced for one vendor
only is a gap, not a default.

## Cross-agent channel

Reach another agent through inspectable state, never through a person
relaying prose between tools:

- A frozen brief that states the goal and the constraints.
- An explicit file or directory boundary.
- A pushed branch, PR, or diff, at an exact revision.
- Verification already run, and its result.

A review from another agent stays read-only on the branch under review.
Reconcile every finding against the live repository state before acting on

### Review finding disposition

Every review finding carries exactly one label, assigned by the reviewer,
not by the session applying the fix:

- **`auto-fix`** — the fix is safe, mechanical, and does not change what the
  code is meant to do. The applying session fixes it without asking.
- **`ask-user`** — the fix touches intent: behavior, a contract, an
  interface, or a tradeoff the reviewer had to guess about. It is
  escalated, with the question stated.

An unlabelled finding defaults to `ask-user`. Full rule:
`delegation-policy.md` in this repo's root.

## Command shapes

These shapes apply in every harness with a permission-gated or
approval-gated command runner:

- Run each read-only inspection command on its own. Do not chain commands
  with `&&`, `;`, or `|` for inspection — chain only when a later command
  genuinely depends on an earlier one's result.
- Scope a git command to its repository explicitly (for example
  `git -C <path> <verb>`). Do not `cd` into a repository first and run a
  bare command.
- Treat a destructive-looking git verb — a hard reset, a history rewrite, a
  forced branch delete, a force-push — as a step that needs an explicit
  human decision, not a default path.
- Avoid an improvised or unfamiliar command shape where a known, working
  shape exists. A novel shape is the most common source of an avoidable
  approval prompt or a silent failure.
- A command form that works in one shell does not always work in another.
  Confirm a new shape once before repeating it across many calls.

## Why a check, not a generator

Two build paths were open. Generate the State section from `gh` and the
CHANGELOG, or read it and report what disagrees. This takes the second.

A generated State section carries only the facts the generator knows. The
judgement around them is the part that helps the next session: which pull
request matters, what a number means, what to do first. A generator deletes
that prose or leaves it beside a machine block that nobody trusts. A check
leaves the writer in charge and refuses to let one class of claim go quiet.

The tool never edits HANDOFF.md. `TestNeverWrites` compares the file bytes
before and after a full run.

## Three rules the report rests on

- **Absent is not zero.** A `gh` call that fails reports UNMEASURED with the
  reason, never an empty set of open pull requests. A missing HANDOFF.md exits
  2, because a deleted file must not report the same green as a correct one.
- **The remote is the authority.** Branches and tags come from `git ls-remote`,
  never from a remote-tracking ref, which is a local cache that can carry the
  stale claim the check exists to catch. `reconcile.py` made the same call.
- **A false DRIFT is the expensive error.** A check that reports a drift which
  is not there trains the reader to skip the output. Every detector
  under-reports rather than guesses, and the convention page states where.

## Measured against the motivating case

`defense-news-classifier`, HANDOFF dated 2026-08-02. Exit code 1, five DRIFT
rows and one UNMEASURED. The row that produced this work:

   329 +        if match:

   331 +    return actions
   332 +
   333 +
   334 +def restated_jobs(jobs_text: str, owner_text: str) -> list:
   335 +    """Jobs marked DONE that the owner-only list still describes as pending.
   336 +
   337 +    THE SIGNAL IS THE JOB'S OWN WORDS, not its number. A number reference alone
   338 +    is a false positive: a finished job legitimately hands one remaining step to
   339 +    the owner, and that step cites the job it came from. The failure this finds
   340 +    is narrower. The owner-only list repeats the job's OWN action in the job's
   341 +    own words, so the same work reads as done in one section and pending in the
   342 +    other.
   343 +
   344 +    The threshold is `_MIN_OVERLAP` shared distinctive words. That is a
   345 +    deliberate floor, and it carries a real limit: a job whose title holds fewer
   346 +    than two distinctive words can never be matched. `conventions/handoff-check.md`
   347 +    states that limit.
   348 +    """
   349 +    stale = []
   350 +    bullets = [(action, significant_words(action))
   351 +               for action in bullet_actions(owner_text)]
   352 +    for number, title in sorted(done_jobs(jobs_text).items()):
   353 +        title_words = significant_words(title)
   354 +        for action, action_words in bullets:
   355 +            shared = title_words & action_words
   356 +            if len(shared) >= _MIN_OVERLAP:
   357 +                stale.append({
   358 +                    "job": number,
   359 +                    "title": _tidy(title),
   360 +                    "owner_entry": _tidy(action),
   361 +                    "shared": sorted(shared),
   362 +                })
   363 +                break
   364 +    return stale
   365 +
   366 +
   367 +def _tidy(text: str) -> str:
   368 +    """One line, with markdown emphasis removed."""
   369 +    return " ".join((text or "").replace("~~", "").replace("**", "")
   370 +                    .replace("`", "").split())

   373 +# --- Record parsers ----------------------------------------------------------
   374 +# Every parser below takes TEXT, not a subprocess. That is what lets the suite
   375 +# cover them with recorded output, with no network and no repo.

   377 +
   378 +def parse_gh_pr_list(payload: str) -> set:
   379 +    """Open pull request numbers from `gh pr list --json number`.
   380 +
   381 +    A payload that does not parse raises. It must never read as an empty set,
   382 +    because an empty set is a real answer that this tool acts on.
   383 +    """
   384 +    data = json.loads(payload)
   385 +    if not isinstance(data, list):
   386 +        raise ValueError("gh pr list did not return a JSON list")
   387 +    return {int(entry["number"]) for entry in data if "number" in entry}
   388 +
   389 +
   390 +def parse_ls_remote_tags(text: str) -> list:
   391 +    """Tag names from `git ls-remote --tags`, sorted by version.
   392 +
   393 +    An annotated tag prints twice. The `^{}` spelling names the commit, so both
   394 +    lines are one tag and the set removes the duplicate. A tag that carries no
   395 +    semantic version is dropped, because the comparison cannot order it.
   396 +    """
   397 +    names = set()
   398 +    for line in (text or "").splitlines():
   399 +        match = _LS_REMOTE_TAG.match(line.strip())
   400 +        if match and parse_version(match.group(2)):
   401 +            names.add(match.group(2))
   402 +    return sorted(names, key=lambda name: parse_version(name) or (0, 0, 0))
   403 +
   404 +
   405 +def parse_ls_remote_head(text: str, ref: str) -> str | None:
   406 +    """The SHA that `ref` points at on the remote, or None when it is absent."""
   407 +    for line in (text or "").splitlines():
   408 +        match = _LS_REMOTE_HEAD.match(line.strip())
   409 +        if match and match.group(2) == ref:
   410 +            return match.group(1)
   411 +    return None

   417 +class CommandError(RuntimeError):
   418 +    """A command failed. The reason is named, and it is never swallowed."""
   419 +
   420 +
   421 +def run(args: list, cwd: Path) -> str:
   422 +    """Run a read-only command and return stdout.
   423 +
   424 +    Every command this tool runs reads. It runs none that writes.
   425 +    """
   426 +    try:
   427 +        result = subprocess.run(
   428 +            args, cwd=str(cwd), capture_output=True, text=True,
   429 +            timeout=_TIMEOUT,
   430 +        )
   431 +    except FileNotFoundError as exc:
   432 +        raise CommandError("%s is not installed" % args[0]) from exc
   433 +    except subprocess.TimeoutExpired as exc:
   434 +        raise CommandError("%s timed out after %ds" % (args[0], _TIMEOUT)) from exc
   435 +    if result.returncode != 0:
   436 +        detail = (result.stderr or result.stdout or "").strip().split("\n")
   437 +        raise CommandError("%s exited %d: %s" % (
   438 +            args[0], result.returncode, detail[0] if detail else "no output"))
   439 +    return result.stdout

   442 +def result_row(check: str, status: str, claimed="", derived="", reason="") -> dict:
   443 +    return {
   444 +        "check": check,
   445 +        "source": CHECK_SOURCE[check],
   446 +        "status": status,
   447 +        "claimed": claimed,
   448 +        "derived": derived,
   449 +        "reason": reason,
   450 +    }

   453 +def check_open_prs(state: str, repo: Path) -> dict:
   454 +    """Compare the State section against `gh pr list`, in two directions.
   455 +
   456 +    Each direction is a separate question, and only the second one reads
   457 +    English:
   458 +
   459 +      stale-open   a pull request the State CALLS open that the forge does not
   460 +                   list. The prose is wrong about a number it names.
   461 +      unmentioned  a pull request the forge lists as open that the State names
   462 +                   NOWHERE. The prose predates it.
   463 +
   464 +    The second direction needs no attribution at all. A number is on the page
   465 +    or it is not, so the detector's under-report cannot produce a false DRIFT
   466 +    there.
   467 +    """
   468 +    claimed = claimed_open_prs(state)
   469 +    named = mentioned_prs(state)
   470 +    try:
   471 +        payload = run(["gh", "pr", "list", "--json", "number"], repo)
   472 +        actual = parse_gh_pr_list(payload)
   473 +    except (CommandError, ValueError, KeyError, TypeError) as exc:
   474 +        return result_row(
   475 +            "open-prs", UNMEASURED,
   476 +            claimed=_numbers(claimed),
   477 +            reason="gh did not answer: %s. An unread forge is not an empty "
   478 +                   "one." % exc,
   479 +        )
   480 +    stale_open = claimed - actual
   481 +    unmentioned = actual - named
   482 +    shown_claimed = "open per State: " + _numbers(claimed)
   483 +    shown_actual = "open per gh: " + _numbers(actual)
   484 +
   485 +    if not stale_open and not unmentioned:
   486 +        if not named and not actual:
   487 +            return result_row(
   488 +                "open-prs", UNMEASURED,
   489 +                reason="neither the State section nor the forge names a pull "
   490 +                       "request",
   491 +            )
   492 +        return result_row("open-prs", MATCH, shown_claimed, shown_actual)
   493 +
   494 +    reasons = []
   495 +    if stale_open:
   496 +        reasons.append("The State calls %s open. The forge does not"
   497 +                       % _numbers(stale_open))
   498 +    if unmentioned:
   499 +        reasons.append("The forge lists %s open. The State never names them"
   500 +                       % _numbers(unmentioned))
   501 +    return result_row("open-prs", DRIFT, shown_claimed, shown_actual,
   502 +                      reason=". ".join(reasons))
   503 +
   504 +
   505 +def check_branch(state: str, repo: Path) -> dict:
   506 +    claimed = claimed_branch(state)
   507 +    try:
   508 +        actual = run(["git", "branch", "--show-current"], repo).strip()
   509 +    except CommandError as exc:
   510 +        return result_row("branch", UNMEASURED, claimed=claimed or "",
   511 +                          reason="git did not answer: %s" % exc)
   512 +    if not claimed:
   513 +        return result_row("branch", UNMEASURED, derived=actual,
   514 +                          reason="the State section names no branch")
   515 +    if claimed == actual:
   516 +        return result_row("branch", MATCH, claimed, actual)
   517 +    return result_row("branch", DRIFT, claimed, actual)
   518 +
   519 +
   520 +def check_main_vs_origin(repo: Path) -> dict:
   521 +    """Compare local `main` against `main` on the remote.
   522 +
   523 +    The remote answers through `git ls-remote`. A remote-tracking ref is a local
   524 +    cache, and it goes stale the moment another machine moves the remote.
   525 +    """
   526 +    try:
   527 +        local = run(["git", "rev-parse", "main"], repo).strip()
   528 +    except CommandError as exc:
   529 +        return result_row("main-vs-origin", UNMEASURED,
   530 +                          reason="this clone has no local `main`: %s" % exc)
   531 +    try:
   532 +        text = run(["git", "ls-remote", "origin", "refs/heads/main"], repo)
   533 +    except CommandError as exc:
   534 +        return result_row("main-vs-origin", UNMEASURED, claimed=local[:9],
   535 +                          reason="the remote did not answer: %s" % exc)
   536 +    remote = parse_ls_remote_head(text, "refs/heads/main")
   537 +    if not remote:
   538 +        return result_row("main-vs-origin", UNMEASURED, claimed=local[:9],
   539 +                          reason="the remote has no `main`")
   540 +    if local == remote:
   541 +        return result_row("main-vs-origin", MATCH, local[:9], remote[:9])
   542 +    return result_row(
   543 +        "main-vs-origin", DRIFT, "local main " + local[:9],
   544 +        "remote main " + remote[:9],
   545 +        reason="the other checks read a tree that the remote does not carry",
   546 +    )
   547 +
   548 +
   549 +def check_latest_tag(state: str, repo: Path) -> dict:
   550 +    """Compare the newest version in State against the newest tag on the remote.
   551 +
   552 +    The check is one-directional. It fires only when the remote is AHEAD. A
   553 +    HANDOFF that mentions an older tag is a correct record of an older day, and
   554 +    a check that called that a drift would fire on every honest file.
   555 +    """
   556 +    claimed = highest_version(state)
   557 +    try:
   558 +        text = run(["git", "ls-remote", "--tags", "origin"], repo)
   559 +    except CommandError as exc:
   560 +        return result_row("latest-tag", UNMEASURED,
   561 +                          claimed=format_version(claimed),
   562 +                          reason="the remote did not answer: %s. An unread "
   563 +                                 "remote is not an untagged one." % exc)
   564 +    tags = parse_ls_remote_tags(text)
   565 +    if not tags:
   566 +        return result_row("latest-tag", UNMEASURED,
   567 +                          claimed=format_version(claimed),
   568 +                          reason="the remote carries no version tag")
   569 +    newest = tags[0]
   570 +    if claimed is None:
   571 +        return result_row("latest-tag", UNMEASURED, derived=newest,
   572 +                          reason="the State section names no version")
   573 +    if (parse_version(newest) or (0, 0, 0)) > claimed:
   574 +        return result_row("latest-tag", DRIFT, format_version(claimed), newest,
   575 +                          reason="the remote is tagged past the newest version "
   576 +                                 "the State section names")
   577 +    return result_row("latest-tag", MATCH, format_version(claimed), newest)
   578 +
   579 +
   580 +def check_changelog_top(state: str, repo: Path) -> dict:
   581 +    """Ask whether State mentions the top released CHANGELOG version.
   582 +
   583 +    This catches a release that shipped before anyone pushed its tag, which the
   584 +    tag check alone cannot see.
   585 +    """
   586 +    path = repo / "CHANGELOG.md"
   587 +    if not path.is_file():
   588 +        return result_row("changelog-top", UNMEASURED,
   589 +                          reason="this repo has no CHANGELOG.md")
   590 +    try:
   591 +        text = path.read_text(encoding="utf-8", errors="replace")
   592 +    except OSError as exc:
   593 +        return result_row("changelog-top", UNMEASURED,
   594 +                          reason="CHANGELOG.md did not open: %s" % exc)
   595 +    top = parse_changelog_top(text)
   596 +    if not top:
   597 +        return result_row("changelog-top", UNMEASURED,
   598 +                          reason="CHANGELOG.md carries no released version "
   599 +                                 "heading")
   600 +    version = parse_version(top)
   601 +    if version in prose_versions(state):
   602 +        return result_row("changelog-top", MATCH, top, top)
   603 +    return result_row("changelog-top", DRIFT, "not mentioned", top,
   604 +                      reason="the State section never names the top released "
   605 +                             "CHANGELOG version")

   607 +
   608 +def check_job_consistency(sections: dict) -> dict:
   609 +    """Find a job that one section closes and another still lists as pending.
   610 +
   611 +    This is the failure that motivated the tool. It reads the HANDOFF against
   612 +    itself, so it needs no system of record.
   613 +    """
   614 +    jobs = find_section(sections, "next jobs")
   615 +    owner = find_section(sections, "owner-only")
   616 +    if jobs is None or owner is None:
   617 +        missing = "Next jobs" if jobs is None else "Owner-only actions pending"
   618 +        return result_row("job-consistency", UNMEASURED,
   619 +                          reason="this HANDOFF has no %s section" % missing)
   620 +    stale = restated_jobs(jobs, owner)
   621 +    if not stale:
   622 +        return result_row(
   623 +            "job-consistency", MATCH,
   624 +            derived="%d job(s) marked DONE" % len(done_jobs(jobs)),
   625 +            reason="the owner-only list restates none of them",
   626 +        )
   627 +    entry = stale[0]
   628 +    return result_row(
   629 +        "job-consistency", DRIFT,
   630 +        claimed="Owner-only pending: %s" % entry["owner_entry"],
   631 +        derived="job %d DONE in Next jobs: %s" % (entry["job"], entry["title"]),
   632 +        reason="one piece of work carries two answers in one file. Shared "
   633 +               "words: %s" % ", ".join(entry["shared"]),
   634 +    )
   635 +
   636 +
   637 +def _numbers(values) -> str:
   638 +    return ", ".join(str(value) for value in sorted(values)) if values else "none"
   639 +

   641 +# --- Driver ------------------------------------------------------------------
   642 +
   643 +
   644 +def check_repo(repo: Path) -> dict:
   645 +    """Run every check against one repo and return the report.
   646 +
   647 +    The caller has already confirmed that HANDOFF.md exists. A missing file is
   648 +    a refusal, and it never reaches here.
   649 +    """
   650 +    text = (repo / "HANDOFF.md").read_text(encoding="utf-8", errors="replace")
   651 +    sections = split_sections(text)
   652 +    state = find_section(sections, "state")
   653 +
   654 +    if state is None:
   655 +        # Four checks read the State section and report that it is absent. The
   656 +        # other two do not depend on it, so they still run. A check that COULD
   657 +        # have answered must not report that it could not.
   658 +        no_state = "HANDOFF.md has no State section"
   659 +        rows = [
   660 +            result_row("open-prs", UNMEASURED, reason=no_state),
   661 +            result_row("branch", UNMEASURED, reason=no_state),
   662 +            check_main_vs_origin(repo),
   663 +            result_row("latest-tag", UNMEASURED, reason=no_state),
   664 +            result_row("changelog-top", UNMEASURED, reason=no_state),
   665 +            check_job_consistency(sections),
   666 +        ]
   667 +    else:
   668 +        rows = [
   669 +            check_open_prs(state, repo),
   670 +            check_branch(state, repo),
   671 +            check_main_vs_origin(repo),
   672 +            check_latest_tag(state, repo),
   673 +            check_changelog_top(state, repo),
   674 +            check_job_consistency(sections),
   675 +        ]
   676 +
   677 +    return {
   678 +        "repo": str(repo),
   679 +        "handoff": str(repo / "HANDOFF.md"),
   680 +        "checks": rows,
   681 +        "drift": sum(1 for row in rows if row["status"] == DRIFT),
   682 +        "unmeasured": sum(1 for row in rows if row["status"] == UNMEASURED),
   683 +    }
   684 +
   685 +
   686 +def format_report(result: dict) -> str:
   687 +    lines = [
   688 +        "handoff check  %s" % result["handoff"],
   689 +        "",
   690 +    ]
   691 +    for row in result["checks"]:
   692 +        lines.append("%-10s %-16s (%s)" % (
   693 +            row["status"], row["check"], row["source"]))
   694 +        if row["status"] == DRIFT:
   695 +            lines.append("    claimed  %s" % (row["claimed"] or "nothing"))
   696 +            lines.append("    derived  %s" % (row["derived"] or "nothing"))
   697 +            if row["reason"]:
   698 +                lines.append("    %s" % row["reason"])
   699 +        elif row["status"] == MATCH:
   700 +            lines.append("    both     %s" % (row["derived"] or row["claimed"]))
   701 +        else:
   702 +            lines.append("    why      %s" % row["reason"])
   703 +            if row["derived"]:
   704 +                lines.append("    derived  %s" % row["derived"])
   705 +        lines.append("")
   706 +    lines.append("%d DRIFT, %d UNMEASURED, %d MATCH." % (
   707 +        result["drift"], result["unmeasured"],
   708 +        len(result["checks"]) - result["drift"] - result["unmeasured"]))
   709 +    lines.append("An UNMEASURED row is not a pass. It is a check that could "
   710 +                 "not run.")
   711 +    lines.append("This tool never edits HANDOFF.md. See "
   712 +                 "conventions/handoff-check.md.")
   713 +    return "\n".join(lines)

   716 +def main(argv: list | None = None) -> int:
   717 +    parser = argparse.ArgumentParser(
   718 +        prog="handoff_check.py",
   719 +        description="Check HANDOFF.md against git and the forge. Reads only; "
   720 +                    "writes nothing.",
   721 +    )
   722 +    parser.add_argument("repo", metavar="REPO",
   723 +                        help="path to the repo whose HANDOFF.md to check")
   724 +    parser.add_argument("--json", action="store_true",
   725 +                        help="emit JSON instead of the table")
   726 +    args = parser.parse_args(argv)
   727 +
   728 +    repo = Path(args.repo).expanduser()
   729 +    if not repo.is_dir():
   730 +        parser.error("repo path does not exist: %s" % repo)
   731 +        return 2
   732 +    if not (repo / "HANDOFF.md").is_file():
   733 +        # A refusal, never a pass. A repo whose HANDOFF someone deleted must
   734 +        # not report the same green as a repo whose HANDOFF is correct.
   735 +        sys.stderr.write(
   736 +            "handoff_check: %s has no HANDOFF.md. Nothing was checked, and "
   737 +            "that is not a pass.\n" % repo)
   738 +        return 2
   739 +
   740 +    result = check_repo(repo)
   741 +    if args.json:
   742 +        json.dump(result, sys.stdout, indent=2)
   743 +        sys.stdout.write("\n")
   744 +    else:
   745 +        sys.stdout.write(format_report(result) + "\n")
   746 +    return 1 if result["drift"] else 0
   747 +
   748 +
   749 +if __name__ == "__main__":
   750 +    sys.exit(main())
